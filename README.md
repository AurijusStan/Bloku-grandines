# Etherium kontraktas

#### Kontrakto paaiškinimas

* Owner'is pradeda loteriją su nustatyta bilieto kaina.
* Dalyviai perka bilietus, kurių vertė laikoma kontrakte.
* Kai savininkas sustabdo loteriją, atsitiktinai parenkamas laimėtojas ir jam išmokama 60% visų pirktų bilietų vertės, o savininkui - 40%.
* Savininkas pradeda naują loteriją ir nustato bilieto kainą.

#### Sutarties funkcijos

* "Enter" - pirkti bilietą.
* pickWinner - parenka nugalėtoją.
* startNewLottery - pradėti naują loteriją ir nustatyti bilieto kainą.
* getBalance - parodo sutartyje esančius bilietų fondus.
* getParticipants - parodo bilietus turinčias pinigines.
